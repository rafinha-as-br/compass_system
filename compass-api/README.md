# Compass System - Backend

API RESTful construída com Spring Boot e PostgreSQL, totalmente conteinerizada com Docker.

## Como rodar localmente

1. Certifique-se de ter o Docker e o Docker Desktop instalados.
2. Clone este repositório.
3. Abra o terminal na pasta raiz e execute:
   `docker-compose up -d --build`
4. A API estará disponível em `http://localhost:8081`.
