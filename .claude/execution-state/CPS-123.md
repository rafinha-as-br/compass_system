## Objetivo
Criar a tela de Dados Pessoais no RouteCraft (menu Conta → Dados Pessoais),
seguindo o padrão de camadas do app. Campos editáveis: Nome, Telefone,
Idade, Gênero (via `PUT /users/{id}`). Somente leitura: CPF, E-mail. Botão
de resetar senha.
