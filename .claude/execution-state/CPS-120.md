Estado: EM_EXECUÇÃO

## Objetivo
Script Python (stdlib) que popula compass-api via endpoints HTTP reais:
5 clientes (POST /api/auth/cadastrar/cliente) e 4 viagens por cliente (uma
por estado do ciclo de vida: route_created, itinerary_created,
travel_started, travel_finished — exatamente 1 "em andamento" por
cliente), com itinerários de passos variados (hosting/stop/travel_segment
com airplane/bus/rental_car).

Corrigido durante a implementação: README documentava campos em português
(nome/idade/sexo/telefone/senha) para /api/auth/cadastrar/cliente, mas a
entidade ClientUser usa inglês (name/age/gender/phone/password) sem
@JsonProperty — script usa os nomes corretos.

Arquivos: `compass-api/scripts/seed_test_data.py`,
`compass-api/scripts/test_seed_test_data.py` (self-check sem rede),
`compass-api/README.md` (documentação).
